# SellerFlow 1단계 — Dashboard v1.1

이번 버전은 사용자가 요청한 메뉴명과 대시보드 구성을 반영한 프론트엔드 프로토타입입니다.

## 메뉴
- 대시보드
- 주문내역
- 도매처 관리
- 상품 연결
- 운송장 관리
- CS 관리
- 마진 계산기
- 설정

## 대시보드
- 연결 필요: 도매처 연결 필요
- 주문서 대기: 도매처에 엑셀 전달
- 운송장 대기: 도매처에 송장 받기
- 쿠팡 등록 가능: 자동 등록 준비됨
- 판매 분석 그래프
  - 주문수 / 매출(원) 서로 다른 색상
  - 7일 / 15일 / 30일 전환

현재 숫자와 그래프 데이터는 1단계 UI 확인용 데모 데이터입니다.
다음 단계에서 실제 주문 데이터와 연결합니다.

## 실행
PC 환경에서는:
npm install
npm run dev

아이패드에서는 다음 단계에서 웹 개발환경에 올려 실행하는 방법을 같이 진행하면 됩니다.
